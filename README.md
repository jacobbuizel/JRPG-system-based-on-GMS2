# JRPG-system-based-on-GMS2
本项目是基于 **GameMaker Studio 2 (GMS2)** 的JRPG游戏系统。  
目标是构建一个可复用、可拓展的JRPG游戏框架，并引入独特的战斗机制：  
- 模仿 **《DELTARUNE》** 和其他类似游戏的大地图探索遇敌  
- 在遇敌后切入类似 **《For The King II》**、**《Dungeons & Dragons》**、**《Pathfinder》**  的小型棋盘式战术回合制战斗

---

## 特性
- **模块化系统设计**：物品栏、装备栏、角色属性、存档系统都已独立封装，以便扩展。
- **动态队伍支持**：角色头像、名字、状态等都根据队伍动态生成，不再依赖固定顺序。  
- **AI与状态机**：NPC有逃跑、追逐、交互等多种AI行为。  
- **输入支持**：键盘、手柄兼容。 
- **音乐与音效系统**：支持 BGM/SFX 淡入淡出、音量调节、无缝切换。

## 当前开发进度
### 已完成的核心功能
- **菜单与UI**：物品栏、装备栏、状态菜单、保存界面
- **物品与装备系统**：获取、丢弃、使用、数量上限、滚动显示
- **存档系统**：保存条件、文件管理
- **角色系统**：属性管理、动态队伍、负重计算
- **技能系统**：管理角色技能、法术
- **AI 与交互**：NPC 状态机（追逐/逃跑/寻路/对话分支）、互动判定优化
- **战斗过渡**：大地图与战斗场景的BGM无缝切换（虽然战斗系统还没实装）
- **时间系统**：游戏时长跟进
- **DEBUG调试功能**：快速保存/读取、强制变更属性，在游戏内按下F1来切换DEBUG

## 项目结构

/notes # 开发者笔记  
/objects # 游戏对象  
/options # 跨平台设置（本项目当前仅支持windos系统）  
/rooms # 房间  
/scripts # 脚本（封装的管理器、工具函数）  
/sounds # 音乐与音效  
/sprites # 精灵素材  

## 使用方法
1. 克隆本仓库：  
   ```bash
   git clone https://github.com/jacobbuizel/JRPG-system-based-on-GMS2.git
   ```
2. 使用GameMaker Studio 2(版本 ≥ 2024.13.1)打开hgame.yyp工程文件。

## Codex / Agent Skill
本仓库包含一个项目专用的 Codex/Agent Skill，用于指导之后安全地修改本 GMS2 项目：

- 路径：`.codex/skills/hgame-gms2-safe-edit/SKILL.md`
- 建议触发方式：在让 Agent 修改项目代码前说明 `Use $hgame-gms2-safe-edit`
- Skill 记录了核心系统、GML 风格、`ds_grid` / struct / enum 数据约定，以及禁止随意改动 `.yy` 资源文件、存档系统和不存在/废弃 API 的约束。
